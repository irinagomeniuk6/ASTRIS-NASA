# Публічний запуск ASTRIS (поточна версія)

**Нова основна інструкція:** [`DEPLOY-GROQ-RENDER.md`](DEPLOY-GROQ-RENDER.md).

ASTRIS 2.7 працює на Render Free із Groq/Qwen AI й Supabase для збереження щоденників.
Для відвідувача не потрібні локальні Ollama, Cloudflare Tunnel чи ввімкнений ПК автора.
Стара інструкція для ASTRIS + Ollama/Tailscale застосовується тільки до локальних тестів, не до нинішнього публічного релізу.
